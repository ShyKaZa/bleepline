First public release of **Voice Guard**, a free, open-source, real-time profanity filter for streamers and creators. It mutes banned words in Discord, game voice chat or any app before they reach your stream or your upload, running entirely on your PC.

## Downloads

| File | What it is |
|---|---|
| **VoiceGuard-Setup.exe** | Installer (recommended). Installs for your Windows user only, no admin rights needed; adds shortcuts and an uninstaller. |
| VoiceGuard-portable-win64.zip | Same app, no install: unzip anywhere and run `VoiceGuard.exe`. |
| VoiceGuard-OBS-plugin.zip | Only the OBS filter, for manual installs (the app can install it for you). Includes its GPL source. |

Windows 10/11, 64-bit. The app isn't code-signed yet, so Windows may show *"Windows protected your PC"*: click **More info → Run anyway**.

## Getting started

1. Run the installer and open Voice Guard.
2. **Setup** tab → **Install everything** (downloads the speech model, about 75 MB).
3. **Live filter** tab → pick where your audio goes → **Start filtering**.

Setup for OBS, Streamlabs/XSplit/Twitch Studio, Discord and recordings is in the [full guide](https://github.com/ShyKaZa/voice-guard/blob/main/SETUP.md).

## What's in 1.0.0

- Live filtering at 500-600 ms: OBS plugin, VB-CABLE mode for other streaming apps, and "filter what I hear"
- Recording cleaner for YouTube uploads (video copied untouched, list of muted words with timestamps)
- Runs on the CPU by default (about 3-4% with the default model); optional NVIDIA GPU
- Silence, beep or your own sound as the censor
- Built-in English list, 25 downloadable language lists, wildcards, phrases, allow list, file import
- Any Whisper model: download from the app or add your own
- Optional early muting for shorter delays
- Dark and light themes, installer, and an uninstaller that can remove everything it downloaded

## Known limitations

- It lowers the risk of a strike but can't guarantee every word is caught: mumbled speech, accents and loud game audio can slip through, and similar-sounding words can be muted.
- English is the best tested. Other languages work with multilingual models and language word lists; set the language instead of auto-detect.
- In the automated OBS test, the latest runs catch 3 of 4 test words (earlier runs caught 4 of 4). Being looked into.
