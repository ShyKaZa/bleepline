**Voice Guard is now Bleepline.** Same app, new name: another project on GitHub was already called VoiceGuard, so this one got a name of its own.

## Downloads

| File | What it is |
|---|---|
| **Bleepline-Setup.exe** | Installer (recommended). Installs for your Windows user only, no admin rights needed; adds shortcuts and an uninstaller. |
| Bleepline-portable-win64.zip | Same app, no install: unzip anywhere and run `Bleepline.exe`. |
| Bleepline-OBS-plugin.zip | Only the OBS filter, for manual installs (the app can install it for you). Includes its GPL source. |

Windows 10/11, 64-bit. The app isn't code-signed yet, so Windows may show *"Windows protected your PC"*: click **More info → Run anyway**.

## Coming from Voice Guard 1.0?

- Run **Bleepline-Setup.exe**. It uninstalls Voice Guard for you and keeps your downloaded models, settings and word lists.
- **OBS users:** in Bleepline's Setup tab, install the OBS plugin again. It replaces the old one, and you need to re-add the filter to your audio sources once (**Filters → + → Bleepline (profanity filter)**), because OBS sees it as a new filter.

## Also new

## Known limitations

- It lowers the risk of a strike but can't guarantee every word is caught: mumbled speech, accents and loud game audio can slip through, and similar-sounding words can be muted.
- English is the best tested. Other languages work with multilingual models and language word lists; set the language instead of auto-detect.
